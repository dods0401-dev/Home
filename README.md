# Domilis

Landing page di Domilis, servizio di gestione degli affitti di medio e lungo periodo con canone garantito.

- `index.html`: pagina unica, senza build. Si apre direttamente nel browser.
- Il modulo della lista d'attesa non invia nulla finché `FORM_ENDPOINT` (in fondo a `index.html`) è vuoto.
- Il simbolo nel logo è un ridisegno SVG: va sostituito con il file vettoriale originale.

# Domilis

Servizio di gestione degli affitti di medio e lungo periodo con canone garantito.

- `index.html`: landing page. **Congelata** al commit `ef18622` (tag locale `landing-v1`): non modificare senza una decisione esplicita.
- `annunci.html`: pagina con annunci di prova (dati dimostrativi).
- `app.html`: prototipo navigabile dell'app mobile, vista proprietario e vista inquilino. Dati dimostrativi, nessun backend.

Sono pagine singole senza build: si aprono direttamente nel browser.

Da fare prima di andare online: collegare il modulo della lista d'attesa (`FORM_ENDPOINT` in `index.html`) e sostituire il simbolo del logo, che è un ridisegno, con il vettoriale originale.
